# SQL-Based Data Leak Detection & Prevention System
**College Mini Project (3rd Year B.Tech CSE - AIML)**

This project is organized in the `sql-data-leak-detector/` folder.

To run the application:
```bash
python app.py
```
or:
```bash
cd sql-data-leak-detector
python app.py
```

Then open in your browser:
**`http://127.0.0.1:5000`**
